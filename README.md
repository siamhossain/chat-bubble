# AI Chat Bubble

A **real-time AI-powered chat bubble** built with **Next.js 14** and **OpenAI API**. This project demonstrates how to integrate OpenAI’s GPT models into a modern React/Next.js application with a floating chat interface.

---

## Features

- Floating chat bubble UI  
- Real-time AI responses using OpenAI GPT-4o-mini  
- Built with **Next.js 14** App Router  
- Edge Runtime API route for fast responses  
- Easy to configure and extend  
- Tailwind CSS for responsive styling

## Getting Started

### **Prerequisites**

- Node.js >= 18.17.0  
- NPM >= 9.0.0  
- OpenAI API key (get it from [platform.openai.com](https://platform.openai.com/))

---

### **Installation**

1. Clone the repository:

```bash
git clone https://github.com/your-username/ai-chat-bubble.git
cd ai-chat-bubble

2. Install dependencies:

npm install


3. Create .env.local at the project root:

OPENAI_API_KEY=your_openai_api_key_here


4. Run the development server:

npm run dev


5. Open http://localhost:3000
 in your browser.
